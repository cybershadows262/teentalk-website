# TeenTalk Website

A simple, responsive TeenTalk website made with **HTML, CSS and JavaScript**. It includes:
- Age-group selection
- Topic selection
- Chat message bubbles
- Keyword-based sample replies
- Mobile-friendly design

## Run it on your laptop

1. Download and unzip `teentalk-website.zip`.
2. Open the `teentalk-website` folder.
3. Double-click `index.html`.
4. It should open in your browser. No Python or installation is required.

## Publish it online with GitHub Pages

You need a free GitHub account.

1. Sign in at https://github.com/ and create a new repository, for example `teentalk-website`.
2. Choose **Public** and create the repository.
3. Click **Add file → Upload files**.
4. Upload `index.html`, `style.css`, `script.js`, and `README.md` from this folder. Make sure `index.html` is in the repository's top-level folder.
5. Click **Commit changes**.
6. Open the repository's **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select branch **main** and folder **/(root)**, then click **Save**.
9. Wait a few minutes. The Pages section will show your website link, usually:
   `https://YOUR-USERNAME.github.io/teentalk-website/`

Replace `YOUR-USERNAME` with your GitHub username. Use the exact URL shown in your repository's Pages settings.

## Important limitations

This project uses a small set of keyword rules, not a real AI model. Replies may be repetitive or miss the meaning of a message. It does not save conversations to a database; messages remain in the open page and disappear when it is refreshed.

Do not enter passwords, addresses, or other sensitive personal information. This is a student demo, not a mental-health service. If someone is unsafe or in immediate danger, they should contact a trusted adult or local emergency services.
